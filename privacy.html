2. 이용 목적

  • 서비스 제공: 팀 공지, 일정, 채팅, 할일, 출석, 첨부파일 보관
  • 계정 관리: 로그인, 본인 확인, 팀 가입 승인
  • 오류 해결과 서비스 개선

3. 구글 사용자 데이터

3-1. 구글 로그인

구글로 로그인하면 구글 계정의 이메일, 이름, 프로필 사진을 받아 서비스 계정을 만들고 표시하는 데에만 씁니다.

3-2. 구글 드라이브 연결 (팀장이 선택한 경우)

  • 요청하는 권한: https://www.googleapis.com/auth/drive.file 하나. 서비스가 직접 만든 파일과 폴더에만 접근하는 권한이며, 드라이브의 다른 파일은 보거나 고치거나 지울 수 없습니다.
  • 하는 일: 팀장 드라이브에 MYO 폴더와 팀, 프로젝트별 폴더를 만들고, 게시글 첨부파일을 그 안에 올립니다. 팀원이 앱에서 첨부를 열면 그 파일을 내려받아 보여 줍니다. 게시글이나 프로젝트를 지우면 해당 파일이나 폴더를 드라이브 휴지통으로 옮깁니다. 팀 또는 프로젝트 이름이 바뀌면 폴더 이름을 맞춥니다.
  • 계정 옮기기: 팀장이 연결된 구글 계정을 바꾸면, 서비스가 이전 계정에 올린 첨부를 새 계정 드라이브로 복사합니다.
  • 보관하는 것: 연결된 구글 계정의 이메일(표시용), 폴더와 파일의 식별값, 드라이브 접근용 갱신 토큰. 갱신 토큰은 서버에만 보관하며 앱 화면이나 다른 팀원에게 전달되지 않습니다.
  • 연결 해제: 팀장이 연결을 끊으면 토큰을 구글에 반납하고 서버에서 연결 정보를 지웁니다. 드라이브에 올라간 파일은 팀장의 것이므로 그대로 남습니다.

3-3. 하지 않는 것

  • 구글 사용자 데이터를 판매하지 않습니다.
  • 광고, 맞춤형 광고에 쓰지 않습니다.
  • AI 모델 학습에 쓰지 않으며, 드라이브 파일을 AI 기능에 보내지 않습니다.
  • 위 기능 제공에 필요한 경우, 법률이 요구하는 경우, 보안 사고 대응을 제외하고 사람이 열람하지 않습니다.

스튜디오 묘 팀 허브가 구글 API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 따릅니다.

Studio MYO Team Hub's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. 보관 기간과 파기

  • 개인정보(이름, 프로필 사진, 생일, 직군, 이력 등): 회원 탈퇴 시 지체 없이 지웁니다. 모든 팀에서도 빠집니다.
  • 팀에 남긴 기록(게시글, 댓글, 채팅, 문서 등): 팀의 기록이라 탈퇴 뒤에도 남으며, 작성자는 "탈퇴한 사용자"로 보입니다.
  • 로그인 이메일과 기기 기록: 탈퇴한 계정으로 다시 들어오지 못하게 남겨 둡니다. 완전 삭제를 원하면 아래 문의처로 요청해 주세요.
  • 오류 기록: 14일이 지나면 자동으로 지웁니다.
  • 구글 드라이브 연결 정보: 연결을 끊거나 팀이 없어지면 지웁니다.
  • 탈퇴 사유: 서비스 개선을 위해 계정과 분리해 보관합니다.
  • 팀을 나간 사유: 그 팀의 관리자가 볼 수 있도록 팀이 있는 동안 보관합니다.
